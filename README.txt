KINDER JAGTER’S VAULT — STARTER PWA (VERSION 0.1)

WHAT'S INCLUDED
- Responsive retro-arcade homepage
- Game library with Minecraft, Call of Duty: Zombies, Rainbow Six Siege,
  ARK: Survival Evolved and ARK: Survival Ascended
- Add-your-own-game form
- Personal journal for tips, Easter eggs, guides and questions
- Discovery checklist
- Exportable JSON backup
- PWA manifest, service worker and app icon

IMPORTANT LIMITATION
This first version stores data in the browser on the current device (localStorage).
It does NOT yet sync between you and your boyfriend or between devices.
Do not enter passwords or sensitive information. A later stage needs a secure
cloud database and sign-in to support shared access.

EASIEST LOCAL PREVIEW
Opening index.html directly lets you try the main features, but PWA installation
and offline caching require the files to be hosted over HTTPS or served locally.

BEGINNER-FRIENDLY PUBLISHING PLAN
1. Create a free GitHub account at https://github.com/ if you don't already have one.
2. Create a new public repository named kinder-jagters-vault.
3. Upload the four app files: index.html, manifest.webmanifest, sw.js, icon.svg.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the main branch and /(root), then Save.
7. Wait for GitHub Pages to publish. It will show your website address in Settings > Pages.
8. Open that HTTPS address on your phone. Use your browser's Add to Home Screen /
   Install option if offered.

For true private shared use, do not treat a public GitHub Pages URL as private.
The content currently lives in each browser separately. Add authentication and
cloud storage before putting private notes in it.
